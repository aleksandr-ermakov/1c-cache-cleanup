# 1c-cache-cleanup

Скрипт очистки кэша информационных баз 1С под Windows.

Находит базы 1С, считает размер их кэша и удаляет кэш — целиком, только программный или только пользовательский. Работает через меню, а для автоматизации есть ключи командной строки.

## Что умеет

Скрипт находит информационные базы 1С и их кэш, показывает размеры и позволяет очистить кэш — полностью или частично.

Работать можно через интерактивное меню или ключами командной строки: очистка без вопросов подходит для автоматизации.

Удалить кэш можно у всех найденных баз, у одной выбранной базы, у осиротевших папок, для которых база уже не зарегистрирована, или по возрасту кэша.

## Требования

- Windows;
- Windows PowerShell 5.1 или PowerShell 7+;
- права на запись в каталоги кэша (обычно достаточно прав своего профиля).

## Быстрый старт

Самый простой способ — запустить обёртку `1c-cache-cleanup.cmd` двойным щелчком или из командной строки:

```
1c-cache-cleanup.cmd
```

Обёртка — небольшой batch-файл рядом со скриптом. Она:

- запускает `powershell.exe` с `-NoProfile -ExecutionPolicy Bypass -File`, поэтому менять политику выполнения на компьютере не нужно;
- берёт путь к `1c-cache-cleanup.ps1` относительно себя, поэтому работает из любого текущего каталога и из ярлыка;
- передаёт скрипту все аргументы как есть (`%*`), включая ключи очистки;
- возвращает код завершения скрипта, поэтому её удобно вызывать из других скриптов и планировщика заданий.

Напрямую из PowerShell:

```
.\1c-cache-cleanup.ps1
```

Если политика выполнения запрещает запуск скриптов, а запускать нужно именно `.ps1`:

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\1c-cache-cleanup.ps1
```

## Меню

При запуске без ключей скрипт показывает меню:

```
Базы с кэшем: 82.
Осиротевшие базы: 40.

Выберите действие с кэшем:
1. Очистить всё (26 061,7 MB)
2. Очистить программный кэш (25 584,0 MB)
3. Очистить пользовательский кэш (477,6 MB)
4. Выбрать базу...
5. Осиротевшие базы...
6. Очистить по возрасту...
0. Выход.
```

- пункты 1–3 очищают кэш всех баз с кэшем и показывают его суммарный размер;
- пункт 4 показывает пронумерованный список баз с размерами программного и пользовательского кэша и итогами; выбрав номер, можно очистить кэш этой базы;
- пункт 5 показывается, только если осиротевшие базы есть: сначала выводится их список, затем действия;
- пункт 6 открывает очистку по возрасту кэша;
- пункт 0 завершает работу.

Пункт 6 показывает подменю:

```
Очистка пользовательского и программного кэша баз, по дате изменения папки кэша.

1. Старше недели (18,0 MB)
2. Старше месяца (15,0 MB)
3. Старше квартала (11,0 MB)
4. Старше года (11,0 MB)
0. Назад
```

Возраст базы — дата изменения папки её кэша; если есть и пользовательский, и программный кэш, берётся более поздняя дата. В скобках — суммарный размер кэшей баз, подходящих под условие. Выбранный пункт удаляет оба кэша этих баз.

## Ключи командной строки

Очистка без меню:

| Ключ                 | Синоним | Что делает                                          |
| -------------------- | ------- | --------------------------------------------------- |
| `-ClearAll`          | `-a`    | удаляет программный и пользовательский кэш всех баз |
| `-ClearProgramCache` | `-p`    | удаляет программный кэш всех баз                    |
| `-ClearUserCache`    | `-u`    | удаляет пользовательский кэш всех баз               |
| `-ClearOrphaned`     | `-o`    | удаляет весь кэш осиротевших баз                    |

Ключи можно совмещать:

```
.\1c-cache-cleanup.ps1 -ClearProgramCache
1c-cache-cleanup.cmd -a
.\1c-cache-cleanup.ps1 -ClearAll -ClearOrphaned
```

Справка:

```
.\1c-cache-cleanup.ps1 -h
.\1c-cache-cleanup.ps1 -Help
```

Дополнительные параметры:

| Параметр            | По умолчанию                         |
| ------------------- | ------------------------------------ |
| `-IbasesPath`       | `%APPDATA%\1C\1CEStart\ibases.v8i`   |
| `-StartCfgPath`     | `%APPDATA%\1C\1CEStart\1cestart.cfg` |
| `-UserCachePath`    | `%APPDATA%\1C\1cv8`                  |
| `-ProgramCachePath` | `%LOCALAPPDATA%\1C\1cv8`             |

Коды возврата: `0` — успех, `1` — ошибка запуска или часть папок удалить не удалось.

## Где лежит кэш 1С

| Кэш              | Каталог                  |
| ---------------- | ------------------------ |
| пользовательский | `%APPDATA%\1C\1cv8`      |
| программный      | `%LOCALAPPDATA%\1C\1cv8` |

Кэш одной базы — это папка, имя которой совпадает с идентификатором (GUID) базы. Дата изменения этой папки считается возрастом базы.

**Осиротевшие базы** — папки кэша с именем-GUID, для которых нет ни одной базы в списках. Обычно это кэш удалённых или переименованных баз; скрипт показывает их отдельно и умеет очищать.

## Безопасность

- удаление безвозвратное, корзина не используется;
- удаляется только каталог вида `<каталог кэша>\<GUID базы>`; перед удалением путь проверяется, служебные и посторонние каталоги не затрагиваются;
- перед очисткой закройте 1С: занятые файлы не удалятся, такие папки попадут в строку «Не удалось удалить»;
- кэш 1С восстанавливается при следующем запуске базы, поэтому удаление безопасно для данных информационной базы.

## Состав репозитория

| Файл                       | Назначение                                     |
| -------------------------- | ---------------------------------------------- |
| `1c-cache-cleanup.ps1`     | основной скрипт                                |
| `1c-cache-cleanup.cmd`     | запуск скрипта через `-ExecutionPolicy Bypass` |
| `etc/ibases.example.v8i`   | пример файла со списком баз                    |
| `etc/1cestart.example.cfg` | пример `1cestart.cfg` с общими списками баз    |

Временные файлы для проверок складываются в `tmp/` (каталог в `.gitignore`).

## Ограничения

- только Windows: используются `%APPDATA%` и `%LOCALAPPDATA%`;
- рассчитан на списки баз 1С 8.x в файлах `ibases.v8i` и `1cestart.cfg`;
- если сетевой общий список не отвечает, запуск может задержаться на сетевом таймауте — список будет пропущен.
